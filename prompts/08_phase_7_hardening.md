Requisitos:

- revisar mensagens de erro;
- tratar cancelamento de seletores;
- tratar JSON grande ou nomes longos de forma razoável;
- tratar timestamps acima de uma hora;
- garantir higienização de nomes;
- garantir ausência de sobrescrita;
- garantir reutilização segura da mídia;
- revisar logs;
- remover código morto;
- atualizar README com uso completo;
- atualizar `docs/ADOBE_API_NOTES.md` com APIs realmente utilizadas;
- registrar limitações conhecidas;
- não adicionar funcionalidades pós-MVP;

- não exportar;
- não salvar automaticamente.

Apresente primeiro uma matriz dos testes de aceitação e o estado esperado de cada um. Depois implemente apenas correções necessárias.

Ao terminar, entregue:

1. checklist T01–T15;
2. arquivos alterados;
3. instruções de instalação e execução;
4. limitações;
5. backlog recomendado, sem implementá-lo.
