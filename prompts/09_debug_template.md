# Prompt 09 — Investigar um erro

Leia `AGENTS.md` e os documentos relevantes. Não faça uma reescrita ampla.

Erro observado:

```text
COLE AQUI A MENSAGEM COMPLETA
```

Contexto:

```text
VERSÃO DO PREMIERE:
VERSÃO DO UXP DEVELOPER TOOL:
FASE ATUAL:
PASSOS PARA REPRODUZIR:
RESULTADO ESPERADO:
RESULTADO OBTIDO:
```

Tarefa:

1. reproduza mentalmente o fluxo;
2. encontre o ponto mais provável;
3. confirme a assinatura das APIs envolvidas no SDK/documentação oficial;
4. proponha a menor correção possível;
5. implemente somente essa correção;
6. adicione log temporário útil, se necessário;
7. explique como validar;
8. não altere arquitetura nem adicione funcionalidades.
