# Prompt 01 — Implementar Fase 0

Leia `AGENTS.md` e os documentos de `docs/`.

Implemente somente a Fase 0 de `docs/ROADMAP.md`.

Objetivo: deixar o plugin carregável no Adobe Premiere com um painel mínimo funcional.

Requisitos:

- preservar o template existente;
- manter JavaScript simples;
- criar uma interface mínima em português;
- incluir título do plugin, texto de status e botão de teste;
- o botão deve alterar o texto de status;
- registrar no README os passos exatos para carregar e depurar pelo UXP Developer Tool;
- não implementar seleção de arquivos;
- não importar mídia;
- não acessar nem modificar projeto;
- não adicionar dependências.

Antes de editar, apresente um resumo dos arquivos que pretende alterar. Depois implemente.

Ao terminar, informe:

1. arquivos alterados;
2. como carregar;
3. como testar;
4. erros de console esperados: nenhum;
5. pendências para a Fase 1.
