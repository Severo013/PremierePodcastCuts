# Prompt 00 — Analisar o repositório

Leia integralmente:

- `AGENTS.md`
- `README.md`
- `docs/PRODUCT_SPEC.md`
- `docs/ARCHITECTURE.md`
- `docs/JSON_FORMAT.md`
- `docs/ROADMAP.md`
- `docs/ACCEPTANCE_TESTS.md`
- `docs/ADOBE_API_NOTES.md`

Depois analise a base atual do plugin, sem alterar arquivos.

Entregue:

1. estrutura atual do repositório;
2. template e tecnologias já presentes;
3. versão de manifest e host configurado;
4. como o painel é carregado;
5. APIs ou declarações TypeScript disponíveis localmente;
6. diferenças entre a base atual e a arquitetura proposta;
7. plano mínimo para concluir apenas a Fase 0;
8. riscos ou pontos que precisam ser confirmados.

Não implemente funcionalidades. Não reestruture o projeto. Não adicione dependências.
